1.0.1 뒤 2026년 10월 12일 저녁까지 바뀐 것들이에요.

### ⚠ 꼭 알아 두세요

- 팔로우가 친구로 바뀌면서 기존 팔로우 기록은 모두 지워졌어요. 친구로 옮겨지지 않으니, 친구는 새로 요청하고 수락해서 맺어 주세요 (#76)

### 새 기능

- 팔로우 대신 친구가 생겼어요. 블로그 머리말이나 글 작성자 칸에서 [친구 요청]을 보내고, 상대가 수락하면 친구가 돼요. 피드와 새 글 알림도 친구 기준이에요 (#76)
- 친구 요청이 오거나 수락되면 알림이 와요 (#76)
- 사이트 머리말에 공지·업데이트 소식이 생겼어요. 제목 목록에서 눌러 글로 들어가요 (#48, #52)
- 글에 파일을 첨부하고, 읽는 사람은 내려받을 수 있어요 (#50)
- [글 등록] 창에서 글 썸네일을 고를 수 있어요. 고르지 않으면 둥지 B 그림이 보여요 (#59)
- 홈 인기 태그 칸에서 인기 태그 글 3개를 보고 화살표로 다른 태그 글로 넘겨요 (#71)
- PC에서 마우스를 따라다니는 픽셀 참새 커서가 생겼어요. 누르면 콕 쪼아요 (#68)

### 화면 디자인

- 새 로고(둥지 B + aseLOG)와 브라우저 탭 아이콘으로 바꿨어요 (#54, #70)
- 네모난 칸·단추를 둥글게 바꾸고 파란 링크 밑줄을 정리했어요 (#60)
- 카테고리 관리 화면을 새로 꾸몄어요 (#72)
- 홈 오른쪽의 소개 칸, 글 화면 작성자 칸의 [블로그 가기]를 뺐어요 (#62, #65)
- 내 블로그의 태그 줄과 글 카드 사이 간격을 맞췄어요 (#63)
- PC에서는 창을 줄여도 배치가 그대로 유지돼요 (#49, #51)

### 사용 편의

- 내 글 관리는 등록 글 탭부터 보여 줘요 (#46, #61)
- 내 글 관리에서 [보기]·[수정] 대신 제목을 누르면 글로 들어가요 (#75)
- 아무것도 쓰지 않고 나간 새 글은 임시글로 남지 않아요 (#61)
- 글쓰기 화면에서 프로필·알림 메뉴가 가려지지 않아요 (#47)
- 프로필 [사진 바꾸기]를 누르면 바로 파일 고르기 창이 떠요 (#53)
- 로그인한 뒤 뒤로가기를 눌러도 로그인 화면이 다시 나오지 않아요 (#67)
- 설정에서 "새 글 기본 공개 범위" 칸을 뺐어요. 새 글은 공개로 시작해요 (#72)
- 태그를 한글로 입력하는 중에도 쉼표로 나눠져요 (#55)

### AI 태그 추천

- 배포 서버에서 AI 태그 추천이 안 되던 문제를 고쳤어요 (#57)
- 본문이 50자 이상일 때 추천해요 (#58)
