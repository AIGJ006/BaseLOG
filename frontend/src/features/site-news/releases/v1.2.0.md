1.1.0 뒤 2026년 10월 13일 저녁까지 바뀐 것들이에요.

### 새 기능

- 계정 메뉴에 [새 키우기]가 생겼어요. 매일 들르면 출석이 되고, 3일 연속마다 새가 한 단계씩 자라요. 모은 포인트로 둥지·소품·새 장식을 해금해서 꾸며요 (#94, #96, #97, #99)
- 글 공개 범위에 "친구 공개"가 생겼어요. 친구만 볼 수 있고, 내 둥지와 친구 피드에도 보여요. 카드 썸네일 왼쪽 위에 "👥 친구 공개" 표시가 붙어요 (#84, #88, #93)
- 비밀 댓글과 비밀 답글을 달 수 있어요. 글쓴이와 댓글 쓴 사람만 내용을 봐요 (#90)
- 친구 요청·친구 목록·피드를 계정 메뉴 [친구 관리] 한 화면에 모았어요 (#82)

### 화면 디자인

- 사이트 색을 초록 계열로 바꿨어요. 브라우저 탭 아이콘도 초록이에요 (#80, #81)
- 화면 문구의 "블로그"를 "둥지"로 바꿨어요 (내 둥지, 둥지 주소 등) (#92)
- 회원 가입을 누르면 이메일·Google·GitHub 가입 방법부터 골라요 (#87)

### 관리

- 관리자 화면에 가입 회원 목록이 생겼고, 머리말에 관리자용 [관리] 단추가 붙었어요 (#86, #89)

### 그 밖에

- 알림 메일 제목 앞말이 [BaseLOG]로 바뀌었어요 (#95)
- 아주 긴 글을 AI 태그 추천에 보낼 때 서버 기록이 깨지던 문제 등 코드 품질 지적을 고쳤어요 (#102)
