## BaseLOG 1.0 출시

티스토리처럼 글을 쓰고, 등록하고, 카테고리로 정리하는 개인 블로그 서비스 BaseLOG의 첫 출시 버전이에요. 2026년 10월 10일 팀 공용 서버(https://baselog.java21.net)에 처음 배포했어요.

### 계정
- 이메일 가입·인증·로그인·로그아웃, 비밀번호 찾기 (#2, #11)
- 구글·깃허브 계정으로 로그인 (#11)
- 회원 탈퇴와 기간 안 복구 (#19)
- 설정 화면: 프로필 사진, 알림, 화면 테마 (#11, #15, #30)

### 글쓰기
- 마크다운 글쓰기, 자동 저장, [임시저장]·[글 등록] (#4, #5, #21, #22)
- 사진 넣기: 붙여넣기·끌어놓기·[파일] 버튼, GIF 지원 (#15)
- 공개 범위(전체 공개·나만 보기) (#9)
- 태그와 자동완성, AI 태그 추천 (#14, #27)
- 2단계 카테고리 만들기와 글 분류 (#24)
- 내 글 관리: 임시글·등록 글·휴지통, 삭제·복구 (#8)

### 읽기와 소통
- 홈 최신 글·인기 글, 글 상세, 개인 블로그 페이지 (#6, #7, #26)
- 글·사람 검색, 블로그 안 검색 (#26)
- 댓글·답글, 좋아요, 조회수 (#17, #18)
- 팔로우와 피드, 알림 🔔 (#20, #25)

### 운영과 안전
- 글·댓글 신고, 관리자 숨김·해제·회원 정지 (#28)
- 다크 모드와 색 대비 검사 (#23)
- 본문 스크립트 차단, 보안 헤더, CSRF 보호, 접근성 점검 (#4, #29)
- GitHub Actions로 공용 서버 자동 배포 (#31, #34~#37)

### 점검 결과 (#29)
백엔드 테스트 4,183건, 화면 테스트 996건, 브라우저 E2E 71건 통과. 글 1.2만·댓글 6만 건에서 주요 화면 22개 응답 0.085초 이내.
